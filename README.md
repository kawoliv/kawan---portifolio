## 📋 Sobre o Projeto

Portfólio desenvolvido com **HTML, CSS e JavaScript puros**, sem frameworks ou dependências externas. O design segue uma estética editorial clara e profissional — fundo claro, tinta escura e um azul de destaque — priorizando tipografia marcante e micro-interações elegantes.

O site apresenta a trajetória, habilidades, projetos e formas de contato de Kawan Oliveira Carneiro.

---

## ✨ Funcionalidades

- **Cursor personalizado** com anel de rastreamento animado
- **Hero section** com nome em destaque e animação de círculos orbitando
- **Ticker animado** com as tecnologias do stack
- **Seção Sobre** com texto e cards de estatísticas
- **Grade de habilidades** dividida em Frontend, Backend e Infra/DevOps
- **Lista de projetos** com hover interativo
- **Linha do tempo de experiência** com formação acadêmica e estágio
- **Formulário de contato** funcional
- **Animações de entrada** via Intersection Observer ao fazer scroll
- **Layout responsivo** para mobile

## 🚀 Como Rodar Localmente

Não é necessário instalar nada. Basta clonar e abrir o arquivo:

```bash
# Clone o repositório
git clone https://github.com/kawoliv/kawan---portifolio.git

# Entre na pasta
cd kawan---portifolio

# Abra no navegador
open index.html
```

Ou use a extensão **Live Server** no VS Code para hot-reload.
